# ComfyUI Hello World Custom Node

A simple custom node for ComfyUI to learn node development.

## Installation

1. Clone or download this repository
2. Place in ComfyUI's `custom_nodes` directory
3. Restart ComfyUI

## Development Setup

### Prerequisites
- Python 3.13
- ComfyUI installed

### Setting up Development Environment

```bash
# Create conda environment
conda create -n comfyui-dev python=3.13 -y
conda activate comfyui-dev

# Install development dependencies
pip install -r requirements.txt
```

## Project Structure
